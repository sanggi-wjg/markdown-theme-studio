## 概述

Nebula Cache 是为读取密集型服务设计的双层分布式缓存。本地层在进程内存中保存最近访问的热点键，远程层则作为整个集群共享的持久化存储。当发生缓存未命中时，请求会被转发到源数据库，查询结果随后写回两个缓存层。

在生产环境中，强烈建议为每个命名空间单独设置过期时间（TTL）。默认值为三百秒，但对于更新频率较低的商品目录数据，延长到三十分钟左右通常不会产生一致性问题。

## 配置项

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `namespace` | 无 | 用于在逻辑上隔离缓存条目的命名空间，部署后无法更改 |
| `ttlSeconds` | 300 | 条目的过期时间，可以按命名空间覆盖 |
| `localTierSize` | 10,000 | 本地层保存的最大条目数，超出后按最久未使用的顺序淘汰 |
| `evictionPolicy` | LRU | 淘汰策略。在访问频率分布不均的负载下，LFU 更为合适 |

## 注意事项

- `evictAll()` 会传播到整个集群，滚动重启期间请勿调用。
